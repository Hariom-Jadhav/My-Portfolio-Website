About me

I'm a final-year Electronics and Computer Engineering student with a strong interest in software development, focused on Java. I've built projects using Core Java concepts such as OOP, arrays, exception handling, collections, multithreading and file handling, and I'm now learning Linux and AWS.

I've developed a Banking Management System using Java, JDBC, and MySQL, applying collections and exception handling. I also built an Expense Tracker using Java, JDBC, and MySQL, along with HTML and CSS to create a simple user interface for displaying transactions.

I also worked on a Hydroseeding Smart Agriculture Advisor, where my role was to train the machine learning model for soil classification.

Beyond software, I built an Arduino-based shoe polishing machine and was a member of the steering department of an autonomous vehicle team, contributing to the development of a steer-by-wire system.
